MOVEMAIL — LOCAL MEDIAPIPE MODEL NOTES
==========================================

Purpose
-------
MoveMail uses MediaPipe Tasks Vision with the Pose Landmarker Lite and Hand
Landmarker models to calculate body or hand landmarks in the browser. The
static runtime and model files are kept inside this project so normal play
does not depend on a CDN.

Expected local files
--------------------
js/vendor/vision_bundle.mjs
assets/models/wasm/                 (the complete Tasks Vision WASM directory)
assets/models/pose_landmarker_lite.task
assets/models/hand_landmarker.task

The application should load these paths, not the source URLs below. If a file is
missing or cannot be loaded, camera play should show a calm tracking error and
offer Camera-free Play. Camera-free Play does not need MediaPipe.

Pinned version and original sources
-----------------------------------
MediaPipe Tasks Vision version: 0.10.35

JavaScript bundle:
https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.35/vision_bundle.mjs

WASM distribution directory:
https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.35/wasm/

Pose Landmarker Lite model (float16, version 1):
https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task

Hand Landmarker model (float16, version 1):
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task

Official web guide:
https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/web_js

Official Hand Landmarker web guide:
https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js

Official model overview and model-card links:
https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/index#models

When refreshing the dependency, replace the bundle and every file in the WASM
directory together. Do not mix files from different Tasks Vision versions.
Retest Chrome, Edge and Safari after any upgrade.

Privacy boundary
----------------
These are static code and model files. Body-pose and hand inference run locally
in the browser. MoveMail must not upload, record or store webcam frames.
The models produce temporary landmarks used only for live movement or
hand-shape matching.
